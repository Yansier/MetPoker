# 开发路线

所有阶段必须完成测试、文档同步和退出审查；未经项目所有者确认不得自动进入下一阶段。

## Phase 1A：项目初始化与设计契约

- 范围：仓库骨架、工程约束、PRD、架构、规则、机器人、数据、API/WS、安全、部署和验收契约。
- 测试/检查：文档一致性、敏感信息、Git/环境状态、阶段边界审计。
- 交付物：根配置、目录骨架及 `docs/` 全套文档。
- 退出条件：复杂规则、筹码守恒、身份隔离、崩溃恢复均有固定口径；所有者完成首轮审查。

## Phase 1A.1：设计契约修正与开发环境准备

- 范围：落实 Q-001 至 Q-006，修正 P1 规则案例和 P2 跨文档冲突，补充权威命令、计时器、重连隐私、账目与金额边界；只读检查 Phase 1B 环境。
- 检查：文档交叉一致性、案例合法性、UTF-8、链接、忽略规则、敏感信息、Git 差异和本机 PHP/Composer/扩展可用性。
- 交付物：修订后的设计契约、审查矩阵和真实环境报告；所有规则测试均标记为待 Phase 1B 实现验收。
- 退出条件：P1/P2 问题无文档冲突、六项决策均为已确认、环境缺口被准确记录，并由项目所有者/架构审查批准进入 1B。

## Phase 1B：德州扑克核心引擎及规则自动化测试

- 范围：纯 PHP 牌/牌堆、状态机、动作合法性、牌型、主/边池和结算；确定性随机与时钟端口。
- 测试：规则单元/属性/回归测试，覆盖单挑、盲注、短码加注权、多层边池、奇数筹码、A2345、无人可下注自动发牌。
- 交付物：Domain 源码、PHPUnit 套件、规则覆盖报告；不含网络、数据库、机器人策略。
- 进入条件：Phase 1A.1 审查获批准；本机具备 64 位 PHP 8.2+、Composer 2 和可安装兼容 PHPUnit 的扩展环境。PDO SQLite、Node/npm、SQLite CLI 不是本阶段阻断项。
- 退出条件：`ACCEPTANCE.md` 的引擎用例实现后全绿，领域层无外部依赖，代码审计通过并获确认。

## Phase 1C：基础机器人策略与模拟对局测试

- 范围：受限决策接口、六类性格、三档难度、合法动作适配、受控随机、12 个配置模板、模拟牌局工具。
- 测试：信息边界、确定性回放、动作永远合法、统计冒烟、余额不足离桌；无人真人不开局。
- 交付物：策略实现、模拟器与测试报告；不接外部 AI。
- 退出条件：策略无私有信息泄露、长时间模拟无非法动作/筹码漂移，所有者接受游戏风格。

## Phase 2A：账号、玩家身份、永久钱包及数据库

- 范围：迁移、PDO 仓储、Account/Player、登录会话、邀请、钱包/托管/流水、战绩、CLI 管理员恢复、后台基础 API。
- 测试：迁移回滚/约束、权限、密码和会话撤销、并发买入、幂等返还、守恒、审计、SQLite busy。
- 交付物：版本化 schema、应用服务、HTTP API 与安全测试；不含实时多人牌局。
- 退出条件：资金与身份测试全绿，备份恢复演练通过，API 契约同步并获确认。

## Phase 2B：多人实时游戏、房间及重连机制

- 范围：Workerman 房间邮箱、WS 协议、座位/旁观、计时、暂停、机器人调度、快照/事件、重连、崩溃恢复编排。
- 测试：并发/重复/过期命令、多身份投影、断线、计时器竞态、进程重启三类结算窗口、房主转移。
- 交付物：实时服务、集成测试和故障注入报告。
- 退出条件：无私牌泄露、同房串行、恢复幂等、两种房间资金隔离，负载目标达标并获确认。

## Phase 3A：游戏前端及基础动画

- 范围：Vue 游戏桌、房间流程、合法动作控件、倒计时、重连反馈、响应式布局、CSS/SVG 牌筹码头像。
- 测试：Vitest 组件/状态测试、关键浏览器手工验收、隐藏信息/无障碍/弱网测试。
- 交付物：可玩前端与基础动画；不实现复杂回放或图表。
- 退出条件：2–9 人关键视图和错误路径可用，前端不自行裁决规则并获体验验收。

## Phase 3B：管理后台及个人档案

- 范围：`/admin`、账号/机器人/筹码/审计/房间管理，个人战绩及历史列表。
- 测试：逐接口后端授权、会话/CSRF、敏感字段投影、统计口径和审计完整性。
- 交付物：后台与个人档案页面、权限测试报告。
- 退出条件：管理员不能获得牌局秘密或作弊能力，练习数据不混入正式战绩。

## Phase 4A：完整联调、规则审计、安全及异常恢复测试

- 范围：端到端联调、规则独立审计、威胁模型、性能/稳定性、故障注入、备份恢复。
- 测试：完整矩阵、长局模拟、依赖和配置审计、WebSocket 滥用、进程/磁盘故障演练。
- 交付物：候选版本、审计清单、已知限制和回归报告。
- 退出条件：无阻断缺陷，守恒校验零差异，恢复演练可重复，所有者签署上线候选。

## Phase 4B：正式部署及实际游戏体验验收

- 范围：Ubuntu/Nginx/HTTPS/WSS 部署、监控、备份计划、小范围真实游戏验收与回滚预案。
- 测试：生产冒烟、证书/安全头、恢复、监控告警、实际多人体验。
- 交付物：部署记录、运维手册、验收反馈与版本标签。
- 退出条件：上线核对完成、备份可恢复、无高优先级体验问题；仍不包含商业化或真实货币能力。
