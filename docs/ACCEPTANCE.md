# 验收标准与测试矩阵

## 1. Phase 1A 文档验收

- 14 份指定文档、根目录配置及前后端骨架存在，中文 UTF-8，无空壳章节。
- PRD/API/WS/数据库对 Account/Player、普通/练习筹码、幂等键和权限使用相同术语。
- 扑克规则对单挑、短盲、完整加注、累计短全押、未跟注退还、边池、平局/奇数筹码和自动发牌有固定案例。
- 管理员、机器人、旁观者和历史接口均不能看到未公开牌或牌堆。
- 崩溃前检查点、结算事务、提交后崩溃和重复恢复均有唯一处理方式。
- `.gitignore` 覆盖 secret、数据库/WAL/SHM、备份、日志和依赖目录；文档无本机绝对路径、真实凭证或玩家数据。
- Phase 1A 不包含业务实现、实际数据库、安装依赖、运行服务或部署；待确认项集中列于 `DECISIONS.md`。

## 3. 关键规则案例

1. **单挑**：按钮=小盲，翻牌前按钮先动，翻牌后大盲先动；断言下一手按钮互换。
2. **不足大盲**：50/100，大盲仅 60；其他人的 call 目标仍是 100，60 层资格正确。
3. **最小加注**：下注 300、加到 700 后下一合法完整加注目标至少 1,100。
4. **单次短全押不重开**：A 到 300（增量 200），B 380 全押；已行动 A 不能 raise。
5. **累计短全押重开**：A 到 300，B 到 380，C 到 500；A 累计面对 +200，可至少加到 700。
6. **三人分池**：A/B/C 分别 1,000/600/300 全押；主池 900、边池 600、A 退 400；总额 1,900。
7. **弃牌投入**：A 投 1,000 后弃，B 600、C 300；A 的跟注部分仍在池中但无资格，超出 600 的 400 退还。
8. **奇数筹码**：301 由两名赢家平分，按钮左侧先遇到者 151，另一人 150；各池独立。
9. **公共牌最佳**：公共皇家同花顺，所有未弃牌者平分且底牌不作比较。
10. **A2345**：轮子顺子顶张 5，输给 6 高顺；同花色不参与破平。
11. **无人可再下注**：所有剩余玩家全押后自动发完一次并结算，无多余超时动作。
12. **全弃至一人**：无需亮牌即获所有已跟注筹码，未跟注超额先退。

## 4. 身份与房间案例

- Bot Player 无 Account/session，真人 token 不能声明或接管 bot player_id。
- 游客加入普通房返回禁止；游客在练习房补充临时筹码后 wallets/ledger/stats 零变化。
- 管理员旁观与普通旁观快照字段一致；历史也不能看到 muck 牌。
- 单真人断线自动暂停并冻结剩余毫秒；重连恢复。两真人时断线不暂停，超时可 check 则 check，否则 fold。
- 已全押玩家断线/离桌仍参与其有资格底池；手末才返还/腾座。
- 房主离开按“已连接、最早入座注册真人”转移；无候选则安全关闭。
- 最后一名真人离开后当前手可结算，下一手不得创建。

## 5. 资金与恢复案例

- 钱包 100,000 买入 10,000：钱包 90,000、escrow 10,000；重复 request_id 不再扣款。
- 赢 2,500 后离桌：钱包最终 102,500，正式净盈亏 +2,500；买入/返还不计盈利。
- 管理员发 5,000：资产增 5,000、游戏净盈亏不变、管理员调整累计和审计更新；管理员调自己相同。
- 机器人余额低于最低买入：不生成筹码、不入座/手末离桌。余额介于最低和默认时按待确认默认方案买入可用余额。
- 结算事务前杀进程：STARTED 手恢复开局栈并 VOIDED；运行恢复两次结果相同。
- 结算提交后、广播前杀进程：重启读取 SETTLED，不再派奖；客户端快照获得结果。
- 返还过程中重启：按 leave business key 重试，不会双返；最终 escrow 为零。
- 人工制造守恒差异：系统停止相关房间新手并告警，不能自动补币。

## 6. 协议与安全案例

- 相同 request_id+相同 payload 返回原响应；相同 ID+不同 payload 返回冲突并审计。
- hand_id 或 expected_version 过期不改变状态；非法金额/非当前玩家动作不推进版本。
- 事件缺号触发快照；身份不同的同版本快照只在允许字段上不同。
- 改变对手底牌/未来牌而保持公开面不变，真人投影、旁观投影与 Bot context 均不变。
- 密码重置/账号禁用立即使旧 HTTP session 和 WS ticket 失效，但不破坏当前手结算。
- secret scan、依赖审计、CSP/CSRF/Origin/安全 Cookie 和 WSS 检查通过。

## 7. 阶段退出报告模板

每阶段报告必须列出：实现范围、未实现项、环境版本、测试命令与结果、覆盖/故障演练、已知缺陷、文档差异、数据迁移/回滚、Git 状态和所有者需确认项。任何资金不守恒、未公开信息泄露、规则错误、无法幂等恢复或阶段越界均为阻断缺陷。
