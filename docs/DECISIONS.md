# 设计决策记录

状态说明：**已确认**来自产品要求；**设计默认值**是 Phase 1A 为消除歧义采用、需在进入相应实现阶段前验收；**待确认**必须由项目所有者选择。

## 已确认

| 编号 | 决策 |
|---|---|
| D-001 | 标准无限注现金桌，2–9 人，无抽水、不自动升盲；首版无锦标赛、前注、Straddle、保险和多次发牌。 |
| D-002 | PHP 8.2+ 纯领域引擎，Vue 3 前端，Workerman WebSocket，SQLite/PDO，单服务器单权威游戏进程。 |
| D-003 | Account 与 Player 分离；Bot Player 永不登录，管理员参局时无额外牌局权限。 |
| D-004 | 普通房永久筹码与练习房临时筹码严格隔离，整数金额、非负约束、正式筹码守恒。 |
| D-005 | 机器人只能看到自身底牌和公开信息，经过与真人相同的合法动作校验；不得无人持续游戏。 |
| D-006 | 未公开底牌、牌堆及未来公共牌不得通过客户端、后台、历史、日志或机器人接口泄露。 |
| D-007 | Phase 1A 只交付文档和骨架，不安装依赖、不建库、不实现业务、不部署、不推送。 |

## 设计默认值

| 编号 | 默认方案 | 理由/生效边界 |
|---|---|---|
| D-101 | 掉线座位保留 120 秒；空房 30 分钟回收，仅旁观者房 15 分钟回收。 | 可配置；多人桌计时不停，单真人桌自动暂停。 |
| D-102 | 房主离开后转给已连接且最早入座的注册真人；无人可接则关闭。 | 避免转给游客/机器人；当前手先按规则收尾。 |
| D-103 | 奇数筹码从按钮左侧第一个仍有资格的获胜者起按顺时针、每次一枚分配。 | 固定、可测试，不按花色决定。 |
| D-104 | 单挑按钮是小盲，翻牌前先行动；翻牌后大盲先行动。 | 标准单挑现金桌口径。 |
| D-105 | 不足额全押单次或累计达到最近一次完整下注/加注幅度时，才对已行动玩家重新开放加注权。 | 以玩家面对的累计增量判定，详见规则文档。 |
| D-106 | 牌局内公开顺序由最后一位主动下注/加注者先亮；无人下注则按钮左侧首位先亮；玩家可自动亮出获胜牌，未公开弃牌不进历史。 | 兼顾可判定和隐私。 |
| D-107 | 崩溃后未提交结算的手牌全部作废，恢复开手检查点；已提交结算不回滚。旧房间关闭并返还桌上余额。 | 恢复可幂等，不强求实时画面续局。 |
| D-108 | SQLite 启用 WAL、foreign_keys、busy_timeout=5000ms；写事务采用短事务和有界退避，最多约 10 秒后失败。 | 具体退避参数实现时压测确认。 |
| D-109 | state_version 每个成功事件批次递增；请求去重记录至少保留房间生命周期加 24 小时，结算幂等键永久保留。 | 支持断线重试和审计。 |
| D-110 | 预置 12 个机器人在部署初始化时生成，其性格映射存数据库配置而非需要保密的源码常量。 | 公开仓库不提供虚假秘密。 |

## 规则冲突处理

发现文档冲突时：安全/隐私和筹码守恒不降级；牌局规则以 `POKER_RULES.md` 为准，数据事务以 `DATABASE.md` 为准，线协议分别以 API/WS 契约为准。冲突必须先更新本文形成单一决策，再进入实现，禁止用代码默默选择另一方案。
